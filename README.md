# PDM 数据库结构浏览器

## 项目简介
这是一个基于 PyQt6 开发的 PDM (PowerDesigner) 文件查看器。它可以帮助开发人员和数据库管理员快速浏览 PDM 文件的数据库表结构、字段属性、主键信息等，无需安装 PowerDesigner。

## 程序功能实现

### 1. PDM 文件解析
- **核心技术**: 利用 Python 内置的 `xml.etree.ElementTree` 模块解析 PDM 的 XML 结构。
- **命名空间处理**: PDM 文件大量使用 XML 命名空间（attribute, collection, object），程序通过预定义的 `NAMESPACES` 字典准确定位节点。
- **主键识别逻辑**: 
  - 预先构建 `Key-Column` 映射表，解析 `<o:Key>` 节点及其引用的 `<o:Column>`。
  - 在解析表结构时，通过 `PrimaryKey` 引用匹配对应的列 ID，从而准确标识主键字段。
- **属性映射**: 将 PDM 内部的 `Mandatory=1` 逻辑映射为用户易于理解的“可空：否”。

### 2. GUI 界面设计
- **框架选择**: 采用 `PyQt6` 构建跨平台的桌面应用界面。
- **响应式布局**:
  - **QSplitter**: 实现左右面板的可拖拽交互，用户可以根据需要调整表列表和表结构的显示比例。
  - **QScrollArea**: 左右面板均配置了滚动条策略（ScrollBarAsNeeded），确保在复杂数据或低分辨率屏幕下依然可用。
- **数据展示**: 使用 `QTableWidget` 展示多达 9 个维度的字段信息，并支持表头交互式宽度调整。

### 3. 交互与优化
- **实时搜索**: 提供模糊查找功能，支持通过表名（Name）或表代码（Code）进行快速过滤。
- **动态样式**: 
  - **字体缩放**: 提供 10px 到 16px 的字体大小调节，实时应用于全局控件。
  - **自动对齐**: 针对主键、必填项等关键标志位进行居中显示，并支持自动调整列宽以适应内容。

### 1. 环境准备
确保您的计算机已安装 Python 3.x 以及 PyQt6 库。如果尚未安装 PyQt6，可以使用以下命令：
```bash
pip install PyQt6
```

### 2. 启动程序
在终端或命令行中切换到项目目录，运行以下命令：
```bash
python pdm_gui.py
```

### 3. 使用步骤
1. **加载 PDM**: 点击界面顶部的 **“选择文件...”** 按钮，在弹出的对话框中选择您的 `.pdm` 文件。
2. **浏览表结构**: 
   - 加载成功后，左侧列表会显示所有数据库表。
   - 直接点击左侧列表中的表名，右侧区域将立即展示该表的所有字段属性。
3. **搜索定位**: 
   - 在 **“模糊查找”** 输入框中输入表名或代码。
   - 按下回车键或点击 **“查询”** 按钮进行过滤。
4. **个性化调整**:
   - **调整布局**: 鼠标悬停在左右面板中间的分割线上，变为双向箭头后即可左右拖动调整宽度。
   - **调整字体**: 通过右上角的 **“字体大小”** 下拉框选择合适的字号，界面将自动刷新显示。
